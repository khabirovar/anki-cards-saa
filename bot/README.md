# Репозиторий, Pages и бот для Mini App

У бота в этом проекте нет своего сервера: он нужен только как точка входа, к которой
Telegram привязывает кнопку, открывающую веб-приложение. Токен приложению не нужен.

Адрес приложения: `https://khabirovar.github.io/anki-cards-saa/`.

## 1. Репозиторий и GitHub Pages

1. Создайте публичный репозиторий `anki-cards-saa` на GitHub, без README и `.gitignore`.
2. Подключите его и отправьте код:

   ```bash
   git remote add origin git@github.com:khabirovar/anki-cards-saa.git
   git push -u origin main
   ```

3. В репозитории откройте **Settings → Pages** и в **Build and deployment → Source**
   выберите **GitHub Actions**.
4. Первый запуск workflow мог упасть, пока Pages не был включён. Тогда перезапустите
   его: **Actions → Deploy to GitHub Pages → Run workflow**.

Если меняется имя репозитория, поменяйте `base` в `app/vite.config.ts`.

## 2. Создать бота

1. Откройте чат с [@BotFather](https://t.me/BotFather).
2. Отправьте `/newbot`, следуйте подсказкам (имя, username, обязательно заканчивается на `bot`).
3. BotFather пришлёт токен вида `123456:ABC-DEF...`. Здесь он не используется. Если хотите
   его сохранить, положите в `bot/.env` (см. `.env.example`) и никогда не коммитьте реальный токен.

## 3. Привязать Mini App

- **Кнопка меню** (проще всего для одного приложения на бота):
  `/setmenubutton` → выбрать бота → отправить URL → задать подпись кнопки (например, «Учить»).
- **Отдельная ссылка вида `t.me/<bot>/<app>`** (если нужен диплинк отдельно от меню):
  `/newapp` → выбрать бота → указать короткое имя приложения и тот же URL.

Прогресс в CloudStorage привязан к боту: при смене бота он не перенесётся.

## 4. Что проверить в Telegram

- Приложение открывается из кнопки меню, оба режима работают.
- Кнопка «Назад» в шапке Telegram возвращает на главный экран.
- При перевороте карточки есть лёгкая вибрация.

## 5. Не обязательно, но приятно

- `/setdescription`, `/setabouttext` — описание бота в профиле.
- `/setuserpic` — аватар.
